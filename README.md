📌 About the Project

Amazon Clone is a front-end web development project that recreates the visual layout of Amazon's homepage. The project focuses on page structure, navigation, search bar design, product sections, banners, and footer styling using HTML and CSS.

✨ Features

- Amazon-inspired navigation bar
- Search bar UI
- Product and category sections
- Banner and product images
- Footer section
- CSS-based styling and layout

🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Nikhil-st/Amazon-Clone-HTML-CSS.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.
