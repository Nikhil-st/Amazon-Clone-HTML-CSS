Amazon Clone — HTML & CSS

A front-end project that recreates the look and layout of Amazon's homepage using HTML and CSS.

Features
- Amazon-inspired navigation bar
- Search bar design
- Product sections and banners
- Footer layout
- CSS styling and page layout

Tech Stack
- HTML5
- CSS3

Run Locally
1. Clone this repository:
   bash
2. Open the project folder in VS Code.
3. Open index.html in your browser or use Live Server.
